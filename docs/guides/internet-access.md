# Як відкрити HGS для друзів через інтернет

Усе налаштовується на сторінці **Network** у HGS. Безкоштовно, без обов'язкових платних сервісів.

## Який режим вибрати

| Ситуація | Режим |
|----------|-------|
| Тестую сам на своєму ПК | **Local** |
| Друзі в моїй Wi-Fi мережі, гра відкривається з диска або з `http://` | **LAN** |
| Друзі з інтернету, гра на GitHub Pages — **рекомендовано** | **Tunnel** |
| Маю публічну IP, домен і сертифікат, хочу без посередників | **Direct** |

Чому для GitHub Pages потрібен тунель або Direct із сертифікатом: сторінка відкривається по `https://`, і браузер
дозволяє їй підключатися лише до захищеного `wss://` з дійсним сертифікатом. Виняток — `ws://localhost` на тому
самому ПК (тому режим Local працює для власних тестів).

## Tunnel (Cloudflare) — найпростіший шлях

1. **Network** → режим **Tunnel** → **Застосувати**.
2. **Завантажити cloudflared** (HGS візьме офіційний файл з `github.com/cloudflare/cloudflared` і перевірить
   контрольну суму) — або вкажіть шлях до вже встановленого `cloudflared.exe`.
3. Тип **Швидкий тунель** → **Запустити тунель**. За кілька секунд з'явиться адреса
   `https://….trycloudflare.com`, а вгорі — «Адреса сервера для гравців».
4. **Перевірити доступність ззовні** — HGS сам звернеться до себе через інтернет і переконається,
   що відповідає саме він.
5. **Games** → у грі **Invite** → **Створити код** → **Копіювати посилання** → надішліть другу.
   Посилання має вигляд `https://ВИ.github.io/гра/?hgs=wss://….trycloudflare.com&invite=КОД`.
   Щоб посилання з'явилося, у `hgs-game.json` гри має бути `client.url`.

Що треба знати про швидкий тунель (HGS показує це і на сторінці):

* адреса **змінюється при кожному запуску** тунелю — після перезапуску надішліть нове посилання
  (старі токени гравців лишаються дійсними, змінюється лише адреса);
* Cloudflare не гарантує доступність безкоштовного тунелю і може змінити умови;
* якщо тунель «падає», HGS перезапускає його (до 3 разів за 10 хв), далі показує помилку.

### Постійний тунель (необов'язково)

Потрібні безкоштовний акаунт Cloudflare і **власний домен**, підключений до Cloudflare (домен зазвичай платний).
У панелі Cloudflare Zero Trust створіть тунель, додайте Public Hostname (наприклад, `play.example.com`) з
сервісом `http://localhost:8765`, скопіюйте токен тунелю. У HGS: тип **Постійний тунель**, публічна адреса
`https://play.example.com`, **Вказати токен тунелю** (зберігається зашифрованим), **Запустити тунель**.

## Direct — пряме підключення (для досвідчених)

Вимоги:

1. **Публічна IP без CGNAT.** Порівняйте «Публічна IP» на сторінці Network з WAN-адресою в налаштуваннях роутера.
   Якщо вони різні або WAN-адреса виду `100.64.x.x`–`100.127.x.x` — у провайдера CGNAT, Direct не працюватиме.
2. **Проброс порту** на роутері: зовнішній TCP-порт → IP цього ПК, порт шлюзу (типово 8765).
   Windows Firewall спитає дозвіл — дозвольте HGS.
3. **Домен.** Безкоштовно — DuckDNS (`ваше-імʼя.duckdns.org`): вкажіть домен і токен DuckDNS, HGS
   оновлюватиме IP кожні 5 хв (вирішує проблему динамічної IP).
4. **TLS-сертифікат** для домену (файли PEM: сертифікат і ключ). Отримати безкоштовно можна, наприклад, у Let's
   Encrypt (через win-acme або certbot з DNS-перевіркою DuckDNS). Автоматичне отримання сертифіката HGS поки
   не робить.

Без сертифіката HGS не ввімкне Direct — інакше браузерні ігри однаково не змогли б підключитися.
Перевірка доступності з самого ПК може не пройти, якщо роутер не підтримує «hairpin NAT»: відкрийте
`https://ваш-домен:порт/hgs/v1/health` з телефону через мобільний інтернет.

## Безпека при доступі з інтернету

* Адмін-панель HGS завжди лише на `127.0.0.1` і ніколи не відкривається в інтернет.
* Вхід без пароля (`auth.mode = "open"`) автоматично вимикається в режимах Tunnel і Direct.
  Використовуйте **коди запрошень** (типово), **пароль гри** (Games → Settings → «Пароль гри…») або **акаунти**.
* Підбір кодів і паролів блокується (5 невдалих спроб за хвилину — блок IP на 5 хв), події пишуться в журнал
  безпеки (Logs → Безпека).
* У `hgs-game.json` вкажіть `client.allowed_origins` (наприклад, `https://ВИ.github.io`), щоб чужі сайти
  не могли підключатися до вашого сервера від імені гравців.
