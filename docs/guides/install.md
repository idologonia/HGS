# Встановлення і запуск HOME GAME SERVER

## Вимоги

* Windows 10 або 11 (64-bit). Права адміністратора **не** потрібні.
* Для ігор у режимі `python`: Python 3.10+ на ПК (або власне `.venv` гри). Для браузерних ігор (`html`)
  Python не потрібен — він уже є всередині HGS.
* Для гри з друзями через інтернет: безкоштовна програма cloudflared (HGS завантажить її сам на сторінці Network).

## Варіант 1. Інсталятор (рекомендовано)

1. Відкрийте репозиторій на GitHub → **Actions** → останній успішний запуск **build-windows** → блок **Artifacts** →
   завантажте **HGS-windows** (або сторінку **Releases**, якщо там є версія).
2. Розпакуйте й запустіть `HGS-Setup-<версія>.exe`. Програма встановлюється у
   `%LOCALAPPDATA%\Programs\HGS` лише для вашого користувача.
3. Запустіть **HOME GAME SERVER** з меню «Пуск».

Windows SmartScreen може попередити «невідомий видавець» (програма не підписана платним сертифікатом):
**Докладніше → Виконати однаково**.

## Варіант 2. Портативна версія

Розпакуйте `HGS-portable-<версія>.zip` у будь-яку папку і запустіть `HGS\HGS.exe`. Поки поруч з `HGS.exe` лежить файл
`portable.txt`, усі дані зберігаються в папці `HGS\data` (зручно для флешки). Видаліть `portable.txt`, щоб дані
зберігалися у `%LOCALAPPDATA%\HGS`.

## Варіант 3. З вихідного коду (для розробки)

```bash
git clone https://github.com/idologonia/HGS
```

```bash
cd HGS
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
pip install -e . --no-deps
python -m hgs
```

Зібрати `.exe` самостійно: `pip install pyinstaller` → `pyinstaller packaging/hgs.spec --noconfirm` →
`dist\HGS\HGS.exe`.

## Перший запуск

1. HGS перевіряє компоненти і запускає серверне ядро (окремий процес). Жоден ігровий сервер не стартує сам.
2. **Games → + Додати гру** → виберіть папку гри (з `hgs-game.json` або опишіть гру у формі).
3. **Start**. Перевірте гру на своєму ПК: адреса сервера — `ws://127.0.0.1:8765`.
4. Для гри з друзями: [налаштування інтернет-доступу](internet-access.md).
5. Нова гра з Claude: [як підключити нову гру](add-new-game.md).

Windows Firewall може спитати дозвіл лише в режимах LAN/Direct — дозвольте для **приватних** мереж.
У режимі Tunnel вхідні порти не відкриваються.

## Де що лежить

| Що | Де |
|----|-----|
| Налаштування, база, логи, збереження ігор | `%LOCALAPPDATA%\HGS` (Settings → «Відкрити папку даних») |
| Логи | `%LOCALAPPDATA%\HGS\logs` і `…\games\<id>\logs` |
| Резервні копії ігор | `%LOCALAPPDATA%\HGS\games\<id>\backups` |

Видалення програми не видаляє ваші дані — видаліть папку `%LOCALAPPDATA%\HGS` вручну, якщо вони не потрібні.

## Якщо щось не працює

* Червоний банер «Ядро зупинено» → **Перезапустити ядро**; причина — у банері та `logs\core.log`.
* «Порт зайнятий» → інша програма використовує порт 8765/8764/8766: змініть порт шлюзу на сторінці Network
  (порти Admin API / Worker Bus — у `settings.json`).
* Гра не стартує → кнопка **Logs** на картці гри; помилка також показана на самій картці.
