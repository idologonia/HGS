# Demo Arena — тестова гра для HGS

Інфраструктурний тест: кожен гравець — кружечок, позиції синхронізуються між браузерами.
Це **не** шаблон, якого мають дотримуватися інші ігри.

Дві версії одного клієнта (`client/index.html`):

| Папка | game_id | Режим | Хто рахує позиції |
|-------|---------|-------|-------------------|
| `relay/` | `demo-arena` | `relay` | кожен клієнт сам, сервер лише пересилає |
| `logic/` | `demo-arena-logic` | `logic` | сервер (`logic/server/logic.py`), клієнти шлють тільки натиснуті клавіші |

## Як спробувати на одному ПК

1. Запустіть HGS → **Games** → **+ Додати гру** → виберіть папку `examples/demo-arena/relay`
   (і/або `examples/demo-arena/logic`) → **Start**.
2. Відкрийте у двох вкладках браузера:
   `examples/demo-arena/client/index.html?game=demo-arena&name=Ann`
   `examples/demo-arena/client/index.html?game=demo-arena&name=Bob`
   (для серверної версії — `game=demo-arena-logic`).
3. Рухайте кружечок стрілками або WASD — у другій вкладці він рухається теж.

Параметри адреси: `hgs` (адреса сервера, типово `ws://127.0.0.1:8765`), `game`, `name`, `room`, `invite`.
Гра відкривається з диска (`file://`) — для тесту на одному ПК цього достатньо.
